+--------------------------------------------------+
|                 BASIC CALCULATOR                 |
+--------------------------------------------------+

A simple calculator built using HTML, CSS, and
JavaScript.

+--------------------------------------------------+
| FEATURES                                         |
+--------------------------------------------------+
| • Addition                                       |
| • Subtraction                                    |
| • Multiplication                                 |
| • Division                                       |
| • Modulus                                        |
| • Clear screen button                            |
| • Delete/Backspace button                        |
| • Keyboard support                               |
| • Real-time result display                       |
| • Shows operation type                           |
+--------------------------------------------------+

+--------------------------------------------------+
| TECHNOLOGIES USED                                |
+--------------------------------------------------+
| • HTML                                           |
| • CSS                                            |
| • JavaScript                                     |
+--------------------------------------------------+

+--------------------------------------------------+
| HOW TO RUN                                       |
+--------------------------------------------------+
| 1. Download the project files                    |
| 2. Open the project folder                       |
| 3. Run index.html in any browser                 |
+--------------------------------------------------+

+--------------------------------------------------+
| KEYBOARD SUPPORT                                 |
+--------------------------------------------------+
| Numbers      : 0 - 9                             |
| Operators    : +  -  *  /  %                     |
| Enter Key    : Calculate result                  |
| Backspace    : Delete last character             |
| Escape Key   : Clear screen                      |
+--------------------------------------------------+

+--------------------------------------------------+
| EXAMPLE                                          |
+--------------------------------------------------+
| Input  : 5 + 3                                   |
| Output : Addition: 8                             |
+--------------------------------------------------+

+--------------------------------------------------+

| • Theme customization                            |
